# Prepare a PR

Produce a description that lets someone outside the conversation understand and review the change.

1. [Inspect](../capabilities/inspect.md) repository instructions, the complete proposed diff and available design and verification inputs.
2. [Describe](../capabilities/describe.md) the implemented outcome. Resolve material discrepancies between intent and scope; identify missing evidence honestly.
3. For a draft request, present the title and body inline. For an authorized create/update request, use [GitHub actions](../capabilities/github-actions.md), preserving useful human-authored context.
4. Read back the published result and confirm repository, base, head and content.

Completion is an accurate inline draft or the requested published update. When scope changes, revise the existing explanation around the final result.
