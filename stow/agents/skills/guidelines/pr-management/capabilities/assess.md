# Assess changes and feedback

Use the requested scope, intent, diff and surrounding contracts to judge whether behavior is correct and the approach is appropriate.

Trace consequential paths through callers, interfaces, state changes and failure handling. Check compatibility, interactions and acceptance criteria. Use implementation summaries and review comments as leads; establish conclusions from evidence.

For each candidate concern, determine whether it is introduced or affected by this change, identify a concrete trigger and impact, and check existing enforcement or tests before reporting it.

Return defects with precise locations, evidence and expected behavior. Separate optional improvements, unresolved design questions and verification limits. For feedback, identify whether it is warranted, already addressed, a question or a disagreement, and explain why. Bring material design changes back to the user.
