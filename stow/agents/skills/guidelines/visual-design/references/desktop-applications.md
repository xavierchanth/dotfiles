# Desktop Applications

Compose the workspace around sustained work and the information people need together.
Balance primary work, navigation, contextual tools, and supporting regions. Use contrast
and spacing to make the active area clear without making every panel compete.

Choose useful density and readable scales. Repeated labels, values, and controls should
form a coherent visual system. Keep tool areas proportionate to their role and allow
the work itself sufficient presence.

Use the platform and existing product's visual language as context. Limit interaction
detail here to its visual consequences: recognizable controls, selection, focus, disabled
states, and clear feedback.

Read [screen adaptation](screen-adaptation.md) for resizable workspaces. Inspect how
regions behave at smaller and larger window sizes, preserving essential context and
avoiding uncontrolled line lengths or stretched controls. Review representative content
and multi-region states rather than only an ideal empty workspace.
