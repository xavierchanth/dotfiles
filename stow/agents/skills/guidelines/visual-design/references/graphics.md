# Graphics

Establish the message, audience, intended size, and viewing context for the standalone
graphic. Start from supplied copy and identity, using the writing skill when the message
needs development.

Concentrate attention according to what must register first and what rewards closer
inspection. Compose typography and imagery together; use scale, placement, cropping,
and contrast to create a deliberate relationship between them.

Choose detail according to the available attention and viewing size. Give essential
information sufficient presence while preserving character through purposeful imagery,
type treatment, color, and ornament.

For a set of related graphics, preserve recognizable identity while adapting composition
to each message and aspect ratio. Inspect actual-size and reduced previews, important
crops, and the delivered export. Check that the message survives the intended context.
