# Coordination Core

Coordinate delegated work through selected context, clear ownership, and proportionate evidence. Apply this shared guidance when acting as Iris, Team Coordinator, or a DIVE coordinator; keep workflow-specific behavior in the owning skill.

Use [assignment-and-return.md](references/assignment-and-return.md) to scale briefs and returns naturally. Use [handoff.md](references/handoff.md) across contexts, [model-selection.md](references/model-selection.md) for delegated agents, and [attention.md](references/attention.md) for monitoring and reporting.

Give each fresh agent one primary role reference that matches the responsibility being assigned. Coordination Core provides [Worker](roles/worker.md), [Researcher](roles/researcher.md), [Explorer](roles/explorer.md), and [Group Coordinator](roles/group-coordinator.md). An owning workflow may provide more specific role references, such as DIVE's Designer, Critic, Implementer, and Verifier.

Prefer the most specific useful role. Add only the selected context and evidence that role needs. Load additional role guidance when responsibilities genuinely overlap, while keeping ownership and the expected return clear.

Prefer compact selected context over inherited history. Use isolated context when independent judgment materially improves the result. Continue useful work while independent assignments run, and sequence work that depends on unsettled decisions or shared mutable state.

Keep Projects, Tasks, Teams, voice interaction, software-delivery stages, and harness mechanics in their owning skills or harness.
