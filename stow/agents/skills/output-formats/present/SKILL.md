---
name: present
description: Use when the user asks for information to be organized, visualized, or presented in a clearer format.
---

Choose the content structure:

- Lists and tables — items, attributes, groups, comparisons, or multidimensional information; read [lists and tables](references/lists-and-tables.md).
- Graphs and hierarchy — relationships, processes, dependencies, nesting, or ownership; read [graphs and hierarchy](references/graphs-and-hierarchy.md).

Choose the delivery surface:

- Inline Markdown when it is sufficient.
- HTML webview for richer composition or interaction; read [HTML webview](references/html-webview.md).
- Notebook for executable, reactive, or exploratory information; read [notebooks](references/notebooks.md).

Prefer the smallest clear format.
